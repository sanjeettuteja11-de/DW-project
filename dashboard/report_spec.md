# IPL Scorebook — Power BI report specification

> The Power BI Desktop project is generated by `dashboard/build_pbip.py` (the source of truth for
> positions, fields and formatting) and checked by `dashboard/validate_pbip.py`. In the project the
> model table `Model` is named `MLModel`.

Report: **IPL Scorebook 2008-2024** (Power BI service, My workspace), built on the
semantic model **IPL Phase Warehouse** (17 import tables from `IPL_PowerBI_Data.xlsx`).
Measures: `dashboard/measures.tmdl`. Theme: `dashboard/IPL_Scorebook_Theme.json`.

Canvas 1280 x 720 per page. Coordinates below are x, y, width, height in canvas pixels.

## Design rules

- Paper background `#F4F1EA`, ink `#1B1F24`, secondary text `#6E6A62`, hairlines `#DDD6C8`.
- One colour per innings phase, used everywhere: Powerplay `#C8553D`, Middle `#2E6F95`, Death `#2F5D50`.
- Headlines are statements in Georgia; labels and numbers on axes in DIN.
- No card boxes or shadows: visuals sit on the paper, separated by rules (a heavy rule under
  the header, hairlines between rows), like a newspaper graphics page.
- Every chart title says what the chart shows; the subtitle says how to read it or what to notice.
- Line charts label series at the line ends instead of a legend.
